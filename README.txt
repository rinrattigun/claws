Положите сюда файлы шрифта Heroika (имена любые из списка ниже, достаточно woff2 или ttf/otf):
  Heroika.woff2 / Heroika.ttf / Heroika.otf               — обычное начертание
  Heroika-Bold.woff2 / Heroika-Bold.ttf / Heroika-Bold.otf — жирное
Если Heroika уже установлена в системе, она подхватится сама (local()).
Без файла используется запасной шрифт Pangolin.
