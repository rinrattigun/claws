# Omegaverse Dynamics (claws)

Расширение SillyTavern: течка, гон, беременность, настроение.

## Время и настроение из инфоблока (v0.5)

Расширение читает инфоблок последнего ответа персонажа (`<infoblock>…</infoblock>`):

- `Дата: 18 октября, суббота, 2008 | 16:43 | …` — по ней идёт время цикла. Течка/гон длится
  `activeDays` суток **времени в чате**, а не число сообщений. Поддерживается и `dd.mm.yyyy`.
- `♂ Имя (Альфа, …) | Состояние: …` — по ключевым словам определяется настроение каждого персонажа.
  Персонаж опознаётся по имени, а если имя не совпало — по вторичному полу в скобках.

Состояние привязано к сообщениям: свайп, правка и удаление последних ответов откатывают время,
течку, настроение и беременность. Случайные броски детерминированы для каждого сообщения.

Настройки — блок «Время из чата». Кнопка «Проверить последнее сообщение» показывает, что именно
расширение нашло в инфоблоке. Если формат другой — меняется тег или задаётся свой regex
с группами `d`, `mon`, `y`, `H`, `M`.
